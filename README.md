# SAY/DO

SAY/DO turns an intention into a time-bound promise: say it, lock it, do it, or let the result count.

## MVP included

- Today screen with one active promise
- Locking flow with a deadline preview
- Self-verification completion flow
- Transparent Bayesian reliability score
- Russian-first product copy
- Pure domain functions for state transitions and score calculation

## Run locally

```bash
npm install
npx expo start
```

Press `a` for Android, `i` for iOS, or scan the QR code with Expo Go.
